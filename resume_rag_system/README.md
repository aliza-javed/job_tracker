## ✨ Features

### 📄 Resume Analyzer
- Upload resume in `.txt`, `.md`, `.docx`, or `.pdf` format
- Automatic section detection (Education, Experience, Skills, Projects)
- AI-powered scoring for each section
- Overall resume ranking (Excellent, Good, Average, Needs Improvement)
- Personalized suggestions for improvement

### 🔍 Job RAG Query
- Ask questions about jobs and careers
- AI-powered answers using Gemini LLM
- Context-aware responses based on job descriptions

### 📝 Resume Builder
- Create professional resumes with live preview
- Multiple templates (Modern, Classic, Minimal)
- Download as PDF
- Save and load resumes from browser storage

### 🎨 User Interface
- Clean, modern design
- Mobile responsive
- Real-time preview updates
- Drag & drop file upload
